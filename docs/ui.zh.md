# 工作区选择界面

[English](ui.md) | 中文

## 摘要

从会话欢迎页、工作区侧栏或 Remote SSH 设置添加 LOCAL 或 SSH 工作区。每个入口都使用一个包含内嵌目录浏览器的对话框。

## 选择与确认

对话框默认选择 LOCAL。加载主机列表不会连接 SSH 主机。从来源菜单选择主机后，才加载该主机的主目录；切换来源会丢弃之前的目录、路径草稿和错误。

使用主目录、上一级、刷新、目录行，或路径输入框与转到按钮浏览。空目录仍可选择。编辑路径不会创建工作区。添加工作区是唯一的确认操作：输入框与已加载目录一致时使用该目录，否则先验证编辑后的路径，再提交返回的规范目录。

Remote SSH 设置以紧凑行显示主机与工作区，后方为高级设置和连接诊断折叠区域。工作区对话框打开或管理操作占用页面时，不能添加主机或移除映射。

## 恢复与取消

目录加载失败时保留已加载的行和路径草稿。重试会重复失败的目录请求；技术详情仍可选择。工作区提交失败时保留选择，并允许用户再次明确提交。

取消、关闭按钮、遮罩或 Escape 会关闭浏览而不创建工作区。关闭或切换来源会中止读取，并忽略迟到的响应。路径验证或提交期间禁用来源切换和取消；如果入口拥有者撤回对话框，则中止请求且不会收到迟到的已选路径回调。

共享对话框恢复入口焦点，并将键盘导航限制在内部。来源菜单打开时，Escape 先关闭菜单。输入法 Enter 不触发浏览，输入法 Escape 不关闭对话框。共享控件和语义主题 token 提供亮暗主题样式；窄窗口会让路径控件和设置行换行。

SSH 执行失败使用独立的本地化摘要，与 Agent Host 不可用区分。即使 SSH 没有输出，详情仍保留阶段与退出码；仅凭 255 不能认定认证失败。只有成功且为空的发现结果才表示未安装嵌入式 Host。详情有长度上限，连接令牌会被遮盖。自定义 SSH 配置不仅控制主机列表，也用于实际连接与测试；服务器参数中的冲突 `-F` 会被拒绝。清空设置恢复默认配置选择；更改设置会清除缓存的传输。

## 高级设置与诊断

偏好只在管理区域展开后加载，加载失败时不能把空默认值保存。普通刷新保留草稿；放弃和恢复默认都不会提交。保存使用当前版本，并通过第二次读取核对返回设置；中断保存后须重新读取以确认结果。更改 SSH 配置需确认释放连接，且存在远端执行或在途文件操作时会拒绝；外部编辑器选项不会替换 Sidebar 预览。

诊断使用客户端预先生成的 id、经过认证的启动/状态/取消请求及可续期的服务端租约。深度检查及可选固定命令终端验证需明确同意。关闭诊断区域或离开页面会请求取消。阶段结果与清理独立显示，基于旧设置的报告标记过期。复制报告只重建允许输出的非敏感事实，不导出原始日志。

## 开发者参考

[流程组件](../src/client/RemoteWorkspaceFlow.tsx)负责来源选择与提交，[内嵌浏览器](../src/client/WorkspaceDirectoryPicker.tsx)负责目录请求与草稿。每次读取都收到 AbortSignal。即使提供者忽略取消，请求代次仍会拒绝旧结果。这些组件只使用本地交互状态，不创建全局 store，也不运行时导入另一个 feature 插件的组件。

[客户端回归测试](../tests/client-operations.spec.tsx)覆盖两种确认、取消、切换主机、草稿验证、signal、受控响应竞争、错误恢复、输入法和设置共享入口行为。[入口测试](../tests/client-entry.spec.ts)检查本地目录服务的 signal 转发及共享流程注册。浏览器主题和视口审查独立于这些 jsdom 检查。
